# Murmur for Windows — from "never run" to a real Windows application

Date: 2026-09-08. Approved direction: keep the existing design tokens (a port of
`DesignSystem.swift`), build on the existing Avalonia app in `windows/`, and make it a
proper Windows application that has actually been run on hardware. The engine
(`Murmur.Speech`, `Murmur.Dictionary`, the shared test vectors) is untouched.

## What the first real-hardware run found

1. **NAudio never ships.** `Murmur.Platform.Windows` is a class library, so its package
   assemblies are not copied to its `bin`, and both the debug copy step and the publish
   step glob `NAudio*.dll` from that folder — which has none. The first key press would
   throw `FileNotFoundException` inside an unobserved task. Fix: `CopyLocalLockFileAssemblies`.
2. **No logging, no fault path.** `DictationEngine` runs `_ = BeginAsync()`; any exception
   vanishes. The panel has no way to say "the microphone is blocked" or "the hook could not
   install". Fix: a file log and a `Faulted` event surfaced on the front panel.
3. **No model.** Windows has no built-in engine, so nothing transcribes until Parakeet is on
   disk. Downloading it by hand from a doc is not a real app. Fix: download from Settings.

## Design

### Platform-neutral core (`Murmur.Core`, `Murmur.Abstractions`)

- `Log`: append-only text log at `%LOCALAPPDATA%\Murmur\murmur.log`, rotated at 1 MB.
- `DictationEngine`: catches faults in both async paths, records `LastFault`, raises
  `Faulted`, always returns to `Idle`. Reports a blocked microphone via
  `IAudioCapture.LooksLikeBlockedMicrophone` (new interface member; fakes updated).
- `IStartupRegistration` (Abstractions): `IsEnabled`, `SetEnabled(bool)`. Windows
  implementation writes `HKCU\...\Run`; resolved by reflection like the other platform types.
- `ITranscriber` stays. `SwitchableTranscriber` (Core) wraps the current engine so a model
  that arrives while the app is running is picked up without a restart.

### Model download (`Murmur.Speech`)

- `ModelDownloader`: downloads the four Parakeet v2 int8 files from the public Hugging Face
  repo into the first default search path, reports progress (bytes, file), verifies sizes
  against known minimums, writes to `.part` then renames so a truncated download never
  looks complete. `HttpMessageHandler` is injectable, so it is tested with a fake.

### The application (`Murmur.App`)

- **Window chrome.** Client area extended into the title bar; the chassis carries its own
  caption strip with the unit name, a model number, and drawn min/max/close keys.
- **Menu bar.** A token-styled Avalonia `Menu`: File, Edit, View, Transport, Help. Every
  action has a key: Ctrl+R record/stop, Ctrl+, settings, Ctrl+F search, Ctrl+N new entry,
  Ctrl+1/2 sections, Ctrl+Q quit, F1 help.
- **Front panel.** Larger VU with a printed scale, a seven-segment tape counter, a scrolling
  level trace on the deck window, an indicator cluster (POWER, HOOK, MIC, MODEL), corner
  screws. All values from `Tokens`; new tokens added rather than inlined (`Shadow`,
  segment geometry, trace geometry).
- **Overlay.** A small non-activating, topmost readout (lamp + VU) shown while the key is
  held in another app, so status is visible without the main window. Never takes focus.
- **Tray.** Icon swaps to a lit record dot while recording; tooltip carries state.
- **Settings.** Hotkey, model (status, DOWNLOAD with progress, OPEN FOLDER), behaviour,
  start with Windows.
- **Typography.** Bahnschrift (a DIN, the industrial standard face) first, then Arial;
  Cascadia Mono / Consolas for numerals.

### Packaging

- `windows/publish.ps1`: self-contained single-file `win-x64` exe with the app icon.
- `windows/install.ps1`: copies to `%LOCALAPPDATA%\Programs\Murmur`, Start Menu shortcut,
  Apps & Features uninstall entry. No admin rights.
- App icon generated by `windows/Tools/MakeIcon.ps1` from the tokens' palette.

## Verification

- 63 existing tests stay green; new tests for `ModelDownloader`, `DictationEngine` faults,
  `SevenSegment` layout, token invariants.
- Real hardware: launch, synthetic Right Ctrl press, log shows hook → capture → transcribe →
  inject; then a human dictation into Notepad.
