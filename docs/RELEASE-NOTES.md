Windows community preview: local dictation, live overlay, dictionary, history, optional Gemini clean-up, quiet sound cues and spoken sending.

Download **Acapella-Windows-x64.zip**, extract it, then double-click **Install.cmd**. Keep the whole extracted folder together. No developer tools or paid AI account are required for local dictation.

See [Windows installation](https://github.com/sidgrove/acapella/blob/main/docs/INSTALL-WINDOWS.md) and [Mac status and developer setup](https://github.com/sidgrove/acapella/blob/main/docs/MAC.md).

This is an unsigned Windows x64 preview. A microphone and an initial speech-model download are required. Optional Gemini clean-up sends transcript text to Google's API using your own key. The Mac implementation is a separate developer build, not a packaged download or feature-parity release.
